# NLP - Emotion Detection

## Project Description

This project is an emotion detection application using IBM Watson NLP.

The application analyzes a given text and detects five emotions:

- Anger
- Disgust
- Fear
- Joy
- Sadness

It also identifies the dominant emotion expressed in the input text.

## Technologies Used

- Python
- Flask
- IBM Watson NLP
- Requests
- HTML/CSS/JavaScript

## Features

- Emotion detection using IBM Watson NLP
- Dominant emotion identification
- Flask web application
- Error handling for invalid or empty input
- Unit testing
